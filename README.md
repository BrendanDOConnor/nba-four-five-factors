# nba-four-five-factors
A comparison of the four factors as described by Dean Oliver (EFG%, FTR, TOV%, OREB%, and those stats for the opposing team) and a new set of five factors (TS%, TOV%, those stats for the opposing team, and REB%). Merging EFG% and FTR into a TS% makes for a better predictor, as does merging the two rebounding rates
